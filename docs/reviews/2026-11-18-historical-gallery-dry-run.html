Как проверили откат

Получили снимки двух записей в транзакции READ ONLY и сверили порядок с публичным API. В изолированный PostgreSQL записали копии и добавили только признаки для перечисленных кадров. Сырые URL не удалялись.

Оба способа отката проверены через Go API и HTML. Отключение фильтра вернуло прежнюю выдачу при сохранённой разметке. Возврат исходных метаданных дал тот же результат с включённым фильтром. Тест сравнил точный состав и порядок URL. Продовые записи не менялись.

Где поможет определение области статьи

Обученные селекторы уже пробуются перед встроенными селекторами и Readability. В запросе к анализатору стоит различить страницу одной статьи и список публикаций, а для статьи просить отдельно указать тело текста, кандидата обложки и блоки исключения. Результат должен проверяться по DOM. Например, тело должно содержать основной текст самой статьи, а исключения можно проверять по навигации, рекомендациям и товарным карточкам. При неясности полезен текущий запасной путь.

Для Blic это уменьшает захват блоков вокруг новости. У The Verge миниатюра пришла из RSS и подтверждена в товарном блоке оригинала. Даже хороший селектор веб-статьи не меняет эту запись RSS автоматически. Пробный прогон не вызывал модель и не менял её конфигурацию.
