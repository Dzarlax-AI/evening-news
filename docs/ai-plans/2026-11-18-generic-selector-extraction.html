Общий путь от AI-анализа к извлечению

Редакция 1 · реализовано и проверено локально · 18 ноября 2026

Что исправляем

Извлекатель должен получать доменно-независимый результат проверки страницы. Список отклоняется только после подтверждения по текущему HTML. Для статьи передаются тело, обложка и исключаемые блоки. Blic и Studenti используются как примеры для проверки. Ни один сайт не получает отдельных правил в коде.

Условия для отдельных источников удалены из этой версии. При выключенном новом пути на свежем снимке Studenti архив по-прежнему извлекается Readability. С включённым путём сильные признаки списка передают снимок на проверку. Подтверждённый список отклоняется.

Где разрыв

go-domain/selectors уже проверяет тип страницы и CSS на HTML. В статье extraction_context возвращает только selector и method из прежнего обучения. go/cmd/extract-service вычисляет NeedsSelectorStudy и держит StudyHTML внутри процесса. Частный HTTP-ответ намеренно его опускает.

Как подключить

  1. Описать необязательный общий результат с типом страницы, селекторами статьи или карточек списка и отпечатком снимка. Добавление поля сохраняет поведение клиентов прежнего формата. Ограничить число и длину CSS, размер входа и ответа. Общую проверку DOM использовать на стороне AI-анализа и перед применением в извлекателе.
  2. В частном пути обработки статьи разрешить одну попытку анализа на снимок для неудачного извлечения или для страницы с сильным сигналом списка при слабом сигнале статьи. Второе условие нужно для архива, который Readability сегодня считает успешным извлечением. Сигнал служит поводом для проверки модели. Для отклонения требуется проверенный ответ и структурные признаки списка.
  3. Передавать ограниченный HTML-снимок только через частный доверенный путь между извлечением и доменным сервисом. Сервис строит компактную структурную сводку для модели и проверяет её ответ на исходном снимке. HTML исключён из публичного API и логов. Проверить идентичность URL и снимка, бюджет и полномочия обработки. Привязать вызов к существующему ограждению попытки и исключить повторный запрос при повторной доставке.
  4. Применять проверенный результат к тому же DOM через частный повтор разбора без повторной загрузки страницы. Для несовпадения отпечатка, неизвестного типа, ошибки модели или утратившего силу CSS использовать обычное извлечение. Исключения применяются к копии DOM. Галерея сохраняет исходные кандидаты для отката и использует существующую проекцию.

Вероятные изменения в go-domain/selectors и go-domain/callbacks, в доработке частного контракта go/service, в go-processing/internal/processing и в применении результата в go/extractor. Обойтись без нового хранилища и обучения по домену. Если жизненный цикл снимка потребует отдельного хранения, сначала вынести это решение на согласование.

Проверки и откат

  • На тех же исходниках прогнать весь путь. Blic и статья Studenti получают проверенные тело и обложку. Архив Studenti отклоняется без текста и медиа. Повторить проверку с синтетическими страницами другого домена и одинаковой разметкой.
  • Проверить старого клиента, редирект, изменившийся DOM, карточки рекомендаций внутри настоящей статьи, короткую статью, сбой AI и повтор обработки. Показать галереи до и после через одну серверную проекцию.
  • Запустить тесты извлекателя, частных HTTP-контрактов и обработчика на временной PostgreSQL. Реальную модель повторно запускать только для согласованных контрольных страниц. Прод доступен для чтения, без деплоя.
  • Оставить общий путь за переключателем на время локальной проверки. Отключение возвращает обычное извлечение. Исторические записи и их сырые медиа не меняются.

Проверка реализации

Пользователь согласовал общий путь без правил в коде для отдельных сайтов и обновление черновика PR №69. Медиа-сессия реализовала общий разбор и частный контракт извлекателя. Координатор подключил проверку полномочий и обработчик. Новый путь включается флагом ARTICLE_SELECTOR_STUDY, по умолчанию он выключен.

  • Рабочая модель gpt-6-luna проанализировала ровно три публичных снимка. Проверенные ответы применены локально через частный HTTP-сервис к тем же снимкам. Повторный разбор не загружал страницы заново. Подменённый SHA отклонён.
  • Blic №18559 сохранил один кадр серверной проекции. Статья Studenti №18588 сохранила два. Проверенные обложки обеих статей совпали с первыми кадрами. Обе статьи проверены явным повторным разбором. Обычные успешные статьи без сильных признаков списка автоматически новый анализ не запускают.
  • У архива Studenti подтверждено 297 разных ссылок. При включённом флаге снимок получен и по HTTP, и из браузерного пути с локальной подстановкой исходного HTML. После подтверждения списка частный сервис вернул терминальное отклонение без тела, обложки и галереи.
  • Проверки затронутых Go-пакетов прошли на временной PostgreSQL и локальных HTTP-портах. Пройдены повторная доставка действующей попытки, отказ при устаревшей попытке и race-тест цепочки обработки. Кэш повторной доставки ограничен временем жизни процесса. При сбое применяется исходное извлечение. Новый механизм хранения не добавлен.

Продовый профиль модели прочитан в транзакции READ ONLY. Записи в продовую БД и деплой не выполнялись.
