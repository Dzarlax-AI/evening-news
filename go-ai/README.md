# go-ai

Provider-neutral Go 1.25 module for one-attempt text and structured JSON generation. Construct `openai.New(ai.Config{...})` or `gemini.New(ai.Config{...})` with an API key, optional HTTP client, and optional collection BaseURL. Defaults are the providers' standard APIs. An OpenAI BaseURL ends in `/v1` and Gemini's ends in `/v1beta/models` (or another version's `/models`); pass the collection, not a per-model template. Each request supplies its own model, prompt, optional temperature, token limit and optional JSON Schema. No retries are performed. Callers retain responsibility for timeouts, retry policy, validating application data and safely handling generated text.

Schemas support object, array, string, number, integer and boolean, with properties, required, items, enum, description, nullable, boolean additionalProperties, and nested anyOf alternatives (including null). Combinations of anyOf with other validation keywords, $defs/$ref, and numeric or length limits are rejected. Types may be uppercase Gemini schema names. Unsupported constructs and schemas over 120,000 bytes are rejected before the HTTP request. OpenAI requires a root object, closed objects and every property required; originally optional properties become nullable. Callers must enforce their original constraints after generation. Request and response bodies are bounded to 8 MiB and 2 MiB respectively.

Usage values are pointers: nil means the count is unknown. Cached input is included in input. OpenAI counts remain unknown when omitted. Gemini uses ProtoJSON, which can omit zero-valued scalar fields: when prompt tokens are reported, an omitted cached count means zero; when candidate tokens are reported, omitted thoughts mean zero. Gemini output is candidate tokens plus thoughts, with thoughts also reported as the reasoning subset. If the corresponding prompt or candidate count is absent, its derived subset and output remain unknown. Total is the provider-reported total, never a sum that duplicates cached or reasoning tokens. See [Gemini usage metadata](https://ai.google.dev/api/generate-content#UsageMetadata) and [ProtoJSON default values](https://protobuf.dev/programming-guides/json/#presence-and-default-values). Refusal and incomplete are distinct response statuses and do not expose refusal text. Errors do not include upstream bodies or transport URLs.
